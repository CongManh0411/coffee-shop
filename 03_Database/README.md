# Database bàn giao

`coffee.sql` là bản sao của `database/coffee.sql`, gồm schema và dữ liệu mẫu (4 danh mục, 11 món, 8 bàn).

Import trên database mới bằng phpMyAdmin. Không import đè database đang dùng để kiểm thử. Thực hiện bước tạo quản lý bằng CLI theo README gốc; SQL không cung cấp tài khoản đăng nhập mẫu. Dữ liệu ca làm được tạo qua ứng dụng sau khi có nhân viên.
